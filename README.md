## ✨ Why AdityaTypo?

Most typing tests simply show your WPM and accuracy.

**AdityaTypo goes one step further.**

It helps you understand:

- ⚡ How fast you type
- 🎯 How accurate you are
- ❌ Which words you repeatedly mistype
- 📈 How your performance changes during a session
- 🧠 Which mistakes deserve focused practice

Your recurring mistakes are collected inside the **Mistake Vault**, allowing you to practice the areas where you actually need improvement.

# 🚀 Features

| Feature | Description |
|---|---|
| ⏱️ **Time Tests** | Practice from 15 seconds up to 15 minutes |
| 📝 **Word Tests** | Choose 10, 25, 50, or 100 words |
| 💬 **Quote Practice** | Improve typing with quote-based passages |
| 💻 **Code Practice** | Practice typing programming-related text |

# 🎧 Keyboard Sound Profiles

Make typing feel more realistic with different sound experiences:

- 🔨 Thocky

- 🧩 Tactile
- 📜 Typewriter
- 🔇 Silent

Audio is generated using the **Web Audio API**, so no audio files are required for the keyboard sounds.

# 📊 Typing Analytics

AdityaTypo tracks multiple performance metrics instead of focusing only on WPM.

### Metrics

**WPM**

Your standard typing speed.

**Raw WPM**

Typing speed before accuracy adjustments.

**Accuracy**

Percentage of correctly typed characters.

**Errors**

Tracks incorrect typing during the session.

**Elapsed Time**

Shows how long you've been typing.

**Session Timeline**

Visualizes how your performance changes throughout the test.

# 🧠 Mistake Vault

One of the core features of AdityaTypo.

Instead of forgetting your mistakes after every test, AdityaType keeps track of words you repeatedly type incorrectly.
